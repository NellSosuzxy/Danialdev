# Personal Website / Portfolio

This is a personal website project built with HTML, CSS, and plain JavaScript. It is designed to be a modern, lightweight, and maintainable portfolio.

##  Project Structure

- **`index.html`**: The main structure and entry point of the website.
- **`css/style.css`**: Custom styling, responsive layouts, and utility classes.
- **`js/main.js`**: Interactive elements, animations, and website logic.
- **`images/`**: Directory for graphical assets, pictures, and icons.

##  Features

- **Responsive Design**: Adapts beautifully to desktop, tablet, and mobile screens.
- **Clean Architecture**: Proper separation of concerns (HTML for structure, CSS for design, JS for logic).
- **Lightweight & Fast**: Zero build tools or heavy packages required.

##  Getting Started

Simply open `index.html` in any modern web browser to view the site locally, or deploy it directly to platforms like GitHub Pages, Vercel, or Netlify.
